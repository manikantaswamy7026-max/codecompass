How it works

Six stages from raw repo to cited answer.

01

Syntax-aware chunking

Tree-sitter splits code at function and class boundaries, not by character count.

02

Hybrid retrieval

BM25 for exact identifiers plus code embeddings, merged with reciprocal rank fusion.

03

Code graph

Calls, imports and references let the agent hop from a function to its callers.

04

Agent loop

LangGraph state machine with search, read, references and test tools, plus a step cap.

05

Incremental index

File hashes and git hooks re-index only what changed.

06

Eval harness

Question set with known answers scores retrieval, correctness and citations.
